ENIGMA
Chris Andrews
Fall 2007


Instructions:
* Launch LC3 Simulator
* Load:
  - Config.obj
  - Menu.obj
  - Rotors.obj
  - Driver.obj (must be loaded last)
* Run Program


Main Menu:

0) Encrypt / Decrypt

	INPUT (A-Z repeateded until ENTER is pressed)

1) Change Plug Board

	A-Z (A-Z)

2) Change Rotor Configuration

	Left Rotor (1-3)
	Ring Setting (A-Z)
	Center Rotor (1-3)
	Ring Setting (A-Z)
	Right Rotor (1-3)
	Ring Setting (A-Z)

3) Change Reflector

	Reflector (A-B)
	
4) Quit
